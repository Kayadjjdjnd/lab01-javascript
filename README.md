## Ответы на контрольные вопросы

**1. Чем отличается `var` от `let` и `const`?**

- `var` — старый способ объявления переменных. Имеет функциональную область видимости (доступен во всей функции), поднимается наверх (hoisting), можно переобъявить.
- `let` — блочная область видимости (доступен только внутри `{}`), нельзя переобъявить в той же области.
- `const` — то же что `let`, но значение нельзя переприсвоить после объявления.

Пример:
```js
var x = 1;
var x = 2; // OK
let y = 1;
let y = 2; // Ошибка!
const z = 5;
z = 10;    // Ошибка!
```

**2. Что такое неявное преобразование типов в JavaScript?**

JavaScript автоматически преобразует типы данных когда это нужно для операции. Например:
```js
"5" + 3     // "53"  — число стало строкой
"5" - 3     // 2     — строка стала числом
true + 1    // 2     — true стало числом 1
```
Это может приводить к неожиданным результатам, поэтому важно понимать как это работает.

**3. Как работает `==` в сравнении с `===`?**

- `==` (нестрогое равенство) — сравнивает значения **с приведением типов**
- `===` (строгое равенство) — сравнивает значения **без приведения типов**, учитывает тип

```js
"5" == 5    // true  — строка приведена к числу
"5" === 5   // false — разные типы
0 == false  // true
0 === false // false
```
Рекомендуется всегда использовать `===`.
